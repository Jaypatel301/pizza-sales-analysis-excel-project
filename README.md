🍕 Pizza Sales Analysis — Excel Dashboard & SQL Validation

📌 Project Overview

This project is an end-to-end Pizza Sales Analysis project built using Microsoft Excel and SQL Server.

The project starts with raw pizza sales data in CSV format, followed by data cleaning and analysis in Excel. An interactive Excel dashboard was then created to visualize key business metrics and sales trends. The results were independently calculated and validated using SQL queries in SQL Server.

🔄 Project Workflow

CSV Data → Excel Data Import → Data Cleaning → Data Analysis → Interactive Dashboard → SQL Server Validation

1. Data Import

Imported the raw pizza sales dataset from a CSV file into Microsoft Excel.

Inspected the dataset and prepared it for analysis.

2. Data Cleaning & Preparation

Cleaned and organized the raw sales data.

Prepared relevant fields required for sales analysis and visualization.

3. Excel Analysis

Used Excel features such as:

Pivot Tables

Pivot Charts

Calculations

Data aggregation

Time-based analysis

4. Interactive Dashboard

Created an interactive dashboard containing:

Total Revenue

Average Order Value

Total Pizzas Sold

Total Orders

Average Pizzas Per Order

Daily order trends

Hourly order trends

Sales by pizza category

Sales by pizza size

Total pizzas sold by category

Top 5 best-selling pizzas

Bottom 5 worst-selling pizzas

📅 Interactive Timeline

An Excel Timeline was added to make the dashboard interactive.

Users can analyze the sales data at different time levels:

Years

Quarters

Months

Days

The dashboard updates dynamically based on the selected time period.

🗄️ SQL Server Validation

The pizza sales dataset was also loaded into SQL Server.

SQL queries were written to independently calculate and verify important metrics and analysis, including:

Total pizzas sold

Total orders

Average pizzas per order

Daily order trends

Hourly order trends

Percentage of sales by pizza category

Percentage of sales by pizza size

Total pizzas sold by category

Top 5 best-selling pizzas

Bottom 5 worst-selling pizzas

The SQL results were compared with the Excel analysis to validate the accuracy of the dashboard results.
